# Portfolio

Personal portfolio / self-presentation site for Andrew Ratnikov, positioning him as a full-stack developer specializing in AI automations and custom integrations for cases where no-code/low-code tools (Make, n8n) fall short.

Live: https://ratnikov.pages.dev/

See [docs/prd.md](docs/prd.md) for the full product spec.

## Status

Pre-implementation — only the PRD exists so far. No source code, build, lint, or test commands yet.

## Stack

- Static site: raw HTML, CSS, and JS — no framework
- Hosted on Cloudflare Pages (`*.pages.dev`)
- Cloudflare Web Analytics

## Content

Single-page site with:

- Hero/positioning section
- Services section
- Projects/portfolio section (grows incrementally as new pet projects ship)
- About section
- Links to GitHub and LinkedIn
- Contact via `mailto:` link
- English / Spanish language toggle

## Non-goals

- Blog / content marketing
- Written case studies or testimonials
- Languages beyond English/Spanish
- Pricing/rate card page
- Contact mechanisms beyond `mailto:`
